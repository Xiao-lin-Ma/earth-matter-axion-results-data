# Open Results Data for Earth Matter Enhanced Axion Dark Matter Search

This repository is intended to host the open results data associated with [arXiv:2602.20260](https://arxiv.org/abs/2602.20260), *Earth Matter Enhanced Axion Dark Matter Search*.

The data release includes:

- axion search results incorporating Earth matter effects; and
- axion search results obtained under the Standard Halo Model (SHM).

The data are expected to be uploaded in September 2026.
